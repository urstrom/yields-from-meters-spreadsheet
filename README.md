# yields-from-meters-spreadsheet
Spreadsheet to calculate annual yields from meter readings

UrStrom uses a spreadsheet with annual meter readings to calculate on-site power consumption, as well as to create overall reports (see e.g.  https://www.urstrom.de/wordpress/wp-content/uploads/2026/09/UrStrom_Projektbericht_2025.pdf).

This repository holds an appropriately anomyzed spreadsheet of accounting of yearly data is done at UrStrom.
